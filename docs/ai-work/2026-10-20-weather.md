## Problem

Night surprise package G: from hole level 3, every 4-7 minutes a 45 s rain makes the grass and the gnomes slippery, so throws, pushes and kicks slide far.

## Summary

- New file `src/systems/weather.ts`, class `Weather` with `update(dt)`, `start()` and `raining`. No other src file touched.
- Timer: dry game seconds count down only at hole level >= 3; each rain draws a new gap of 240-420 s.
- Start: one pass over `physics.forEachCollider` (collect first, then `setFriction` after the iteration): colliders whose membership has GROUND get 0.04, GNOME get 0.06; the old value is kept per collider handle. The pass repeats once per second during the rain, so new gnomes and the ground slabs rebuilt by a hole level-up get wet too. Banner `hud.banner('RAIN', 'Everything slides for 45 s')`.
- End: every saved handle that still exists gets its own old value back (`physics.getCollider(h)?.setFriction(f)`; eaten gnomes return null), the map is cleared.
- Sky: tone mapping is on (`ACESFilmicToneMapping` in `main.ts`), so `renderer.toneMappingExposure` eases from the current value (1.05) to 0.85 over 1 s with `outCubic`, and back to the saved value over 1 s after the rain. The dry value is read at rain start, not hard-coded.
- Streaks: one `THREE.LineSegments` with 300 segments, created once, hidden when dry, no lights. Drops fall at 22 m/s in a 20 x 20 m box that follows the camera, 1 m streaks with a slight tilt; opacity fades in and out with the same 1 s ease. No per-frame allocation (two Float32Arrays reused).
- Ladder: rung 2 for `forEachCollider`/`setFriction`, `hud.banner`, `outCubic`, `rand`; rung 6 (minimum code) for the streaks.

## Deviations from the plan

- Wet friction 0.04 (ground) / 0.06 (gnome) instead of 0.1 / 0.15. Reason: with the plan's numbers the gnome slid only 9.57 m (Rapier averages the two frictions, avg 0.125, plus the gnome's linear damping 0.15), so "Gotowe, gdy" line 2 (>= 15 m) failed. With 0.04 / 0.06 it slides 17.9 m. The measurable line wins over the means; the orchestrator or PP can raise the numbers if ice feels too strong.
- No `fx.wind` streaks. Reason: `fx.wind` emits soft 0.7-size puffs that drift up (puff pool gravity -1.5), so they read as fog blobs, not rain; and 10 per frame with 0.6 s life needs about 360 live puffs from a pool of 300, which would steal the landing dust and smoke puffs from the rest of the game. Own `LineSegments` instead, as the order allowed.

## Rejected

- Fog/sky colour tint: not needed, tone mapping is on.
- Rain sound: not in the plan.
- Saving rain state: rebirth reloads the page and the frictions come fresh from the code, so a save without the key is the normal case.

# Plan: shop as a bigger computer-style screen with the buyable count

Spec: PP, 2026-10-20: "zrob ten sklep wiekszym ekranem bardziej komputerowy styl. Dodaj tam ilosc mozliwych do kupienia rzeczy." Orchestrator brief: old desktop-OS / monitor window look (title bar, window chrome, taskbar-like tabs, monospace, light scanlines), use most of the screen, the skill tree uses the extra space (bigger nodes, less scrolling), usable at 640x360, a prominent total next to the per-tab green badges (batch 1, `2026-10-20-plan-hud-right-stack.md` step C, already in `shop.ts:287-289, :396, :413-417`).
Trivial check: two files (`shop.ts`, `icons.ts`) but a DOM contract read by ten headless scenarios, layout constants shared by nine tabs, a window animation under animation rule 12, and chrome CSS shared with the legend.

### Alternatives rejected
- (a) Keep `CW/CH` and scale the tree up by transform (`k ≤ 1.3`): the 52 px thumbnails blur at 1.3x on DPR 1; the pictures are yesterday's "graphics".
- (b) Light Win95-style chrome (grey bevels): clashes with the dark HUD panels and the node ring colours (green/blue/gold), each state would need re-tinting.
- (c) A pixel font (VT323 / Press Start 2P) through the existing Google Fonts `@import`: allowed by the repo's pattern, but pixel fonts are hard to read at 11-13 px (names, prices) and add a network fetch; system monospace gives the console look for free.
- (d) 100vw x 100vh shop: hides the game entirely, no window feel; 96 x 92 keeps the monitor frame.
- (e) Height-fit at every size: `k = 0.42` at 640x360, unreadable; hence the 0.8 threshold.
- (f) Chrome CSS in `style.css`: shared with the legend; scoping under `.shop.skill` in the module string is the existing pattern (`shop.ts:12`).
- (g) Flicker / glitch loop on the overlay: not asked, and an infinite animation needs a hidden-stops check like line 27 of the previous plan.

## Review: impact (plan-impact)

Verdict: BLOCK

Missing from the plan:
- [High] `src/ui/shop.ts:392` `render()` rebuilds `this.el.innerHTML`, so `.shop-win` is a new element on every call. Callers: `open()` :165, tab click :128, `buy()` :218, `buyLand()` :238.

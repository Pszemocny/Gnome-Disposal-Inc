## Plan v0 (plan-author)

### Goal
A lever beside the factory turns Auto Crank off and on (saved), and every placeable tool except the crate and the panel carries a fuse box with `fuses` level slots: a saboteur hit blows one fuse (green → red), the tool breaks only when no green fuse is left, and each E on the tool swaps one red fuse for a green one with a pop animation.

### Assumptions (numbered)
1. "max 5 gnomów" = up to 5 fuses per tool, one upgrade with 5 levels, not five separate upgrades.
2. A tool with fuses left keeps working after a hit (fuses are lives, not a timer).
3. Hits to break = fuses + 1 (open decision 1); repair presses from broken = max(1, fuses).
4. The lever is a world object next to the factory, used with E like the desk and the tools, not a HUD checkbox.
5. Hits land at `m.pos` (home post for robots), as today; the fuse box rides on the truck.
6. The fuse box only renders when `fuses ≥ 1`; at L0 nothing changes visually.

### Alternatives rejected
- (a) HUD/menu checkbox for Auto Crank: PP said "przełącznik obok" (next to it); a HUD toggle also needs a key or mouse mode.
- (b) Five chained upgrades `fuse1..fuse5` with `requires`: five ids for one number; a 5-level upgrade is the repo pattern.
- (c) Fuse box as one merged mesh with vertex-colour updates (1 draw call per tool): no per-fuse pop animation; the attribute update per hit is more code than 5 small meshes.
- (d) Persisting `blown` in `PlacedMachine`: `broken` is not persisted today; same rule (open decision 6).
- (e) Robots immune to saboteurs: rejected in `2026-10-20-robots-more.md`; fuses are the asked-for alternative.

### Chosen variant

# Polish round, Package C: guidance and UI (2026-10-19)

## Problem

PP after playtesting: the game feels weak. Package C of `2026-10-19-plan-polish-round.md` makes the player always know where to go and what a purchase or a held gnome is worth: goal waypoint, clearer shop, clearer magnet and combo panels, controls help on `H`.

Done when (from the plan):
1. goal "Make gnomes" active, player looking away from the factory → an arrow element is visible at the screen edge; looking at the factory → a marker with `m` text is visible
2. money ≥ cost of Running Shoes → that shop row has the afford class; a `???` (locked) row has no afford class
3. holding a 2 kg gnome → the magnet panel contains `heavy` and a `$` value
4. pressing `H` toggles the help panel visibility

## Summary

- `goals.ts`: every goal has a `where` target (factory / hole / shop / crate / none); `Goals.targetPos()` returns its world position. A crate goal points to the shop until a crate is placed. Only "Use the magnet" has no target (gnomes are everywhere).
- `hud.ts`: waypoint (marker `NN m` over the target when on screen, arrow at the screen edge when not; a target behind the player parks the arrow on the left or right edge, the side to turn to). Magnet panel shows a coloured weight class badge and `worth $X` (type value x tier value x `valueScale` x `comboMult`, no trick bonus). Combo panel: SVG ring around the multiplier shrinks with the combo timer, cap on a small line below. Controls help panel (Moving / Magnet / Placing tools) on the left, toggled with `H`, shown automatically while `stats.playTime < 20`; the old one-line help became a small `H controls` hint.
- `shop.ts`: `afford` row class (green left border) plus `AFFORD` badge for affordable, unlocked, not maxed rows (upgrades and the next land plot); `NEW` badge for ids unlocked since the last visit (set kept in memory, seeded at load, updated on close); description line gets `(now: x, next: y)` for speed, magPower, throw, magnetRange, value, factorySpeed, comboCap, crateSize.
- `menu.ts`: the "how to play" list mentions `H` for all controls.
- `style.css`: styles for all of the above; old `.combo-bar` styles removed.

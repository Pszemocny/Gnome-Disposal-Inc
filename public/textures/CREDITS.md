# Texture credits

All textures are CC0 (public domain). Only the colour (base colour) map of each asset is used; normal, roughness, height and AO maps were not shipped. Downloaded 2026-10-20, processed on macOS with `sips` (resize, JPEG quality) and `ffmpeg` (tone changes listed below).

- `grass_diff.jpg` (1024², q75): ambientCG, Grass001, https://ambientcg.com/view?id=Grass001, CC0. 1K-JPG Color map, blurred (gaussian sigma 0.8) and brightened (gamma 1.45, saturation 0.95) for a softer, painted look.
- `dirt_diff.jpg` (512², q80): 3dtextures.me (Katsukagi), Stylized Ground 002, https://3dtextures.me/2024/06/07/stylized-ground-002/, CC0. Base colour map, resized.
- `wood_diff.jpg` (512², q80): 3dtextures.me (Katsukagi), Stylized Wood Planks 002, https://3dtextures.me/2024/07/19/stylized-wood-planks-002/, CC0. Base colour map, resized.
- `roof_diff.jpg` (512², q80): 3dtextures.me (Katsukagi), Stylized Roof Tiles 001, https://3dtextures.me/2024/06/27/stylized-roof-tiles-001/, CC0. Base colour map, resized.
- `plaster_diff.jpg` (512², q80): ambientCG, Plaster001, https://ambientcg.com/view?id=Plaster001, CC0. 1K-JPG Color map, resized.
- `metal_diff.jpg` (512², q80): ambientCG, MetalPlates006, https://ambientcg.com/view?id=MetalPlates006, CC0. 1K-JPG Color map, resized, converted to grey, normalised and lifted to the 90-255 range, so it lightens rather than darkens the factory's vertex colours.
- `mottle.jpg` (256², q80): ambientCG, Rock030, https://ambientcg.com/view?id=Rock030, CC0. 1K-JPG Color map, resized, converted to grey, blurred (sigma 1.5), normalised and lifted to the 175-255 range; used as a soft grain under the vertex colours of trees and bushes.
